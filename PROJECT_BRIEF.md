# PROJECT BRIEF --- Introdução do Site

## 1. Foco atual

O foco deste projeto, neste momento, é EXCLUSIVAMENTE a introdução do
site.

Não implementar outras seções da landing page enquanto a introdução não
estiver definida e aprovada.

------------------------------------------------------------------------

## 2. Conceito da introdução

A página deve começar com uma abertura cinematográfica, profissional e
moderna, funcionando como uma introdução independente antes da landing
page principal.

A referência estética inicial é o estilo visual de eventos de basquete
3x3 da FIBA.

A introdução não deve parecer um template genérico de landing page.

Ela deve transmitir:

-   Esporte
-   Energia
-   Competitividade
-   Profissionalismo
-   Modernidade
-   Expectativa

------------------------------------------------------------------------

## 3. Estrutura e fluxo

### Estado inicial

-   Tela ocupando 100% da viewport.
-   Fundo predominantemente escuro.
-   Estética esportiva.
-   Texturas e elementos visuais sutis.
-   Composição limpa, sem excesso de elementos.

### Etapa 1 --- Entrada da identidade

A logo deve surgir inicialmente pequena e com baixa opacidade.

A entrada deve utilizar uma animação suave combinando:

-   Fade-in
-   Scale-up

A animação deve ser elegante, fluida e sem exageros.

### Etapa 2 --- Mensagem de boas-vindas

Após a entrada da logo, deve aparecer uma mensagem de boas-vindas de
forma sequencial e suave.

Conceito:

**BEM-VINDO**

seguido de:

**AO TORNEIO**

A apresentação do texto deve manter o caráter cinematográfico da
abertura.

### Etapa 3 --- CTA

Depois da mensagem principal, deve aparecer o botão:

**ENTRAR NO EVENTO**

O CTA deve possuir destaque visual, mantendo a estética minimalista e
profissional.

### Etapa 4 --- Transição

Ao clicar em **ENTRAR NO EVENTO**:

-   A introdução deve desaparecer por meio de uma transição suave.
-   A transição deve ser cinematográfica.
-   Não utilizar cortes bruscos.
-   A sensação deve ser de entrada no evento/site.
-   A próxima etapa pode inicialmente ser apenas um estado
    vazio/placeholder, pois as demais seções ainda não fazem parte do
    escopo atual.

Podem ser utilizadas combinações de:

-   Opacity
-   Transform
-   Scale
-   Blur
-   Movimento de elementos

desde que o resultado seja fluido e profissional.

------------------------------------------------------------------------

## 4. Identidade visual oficial

### Regra obrigatória

A imagem fornecida pelo usuário com a marca **BASKET WORKING** é a
referência oficial da identidade visual do projeto.

A paleta de cores presente nessa referência deve ser considerada
**obrigatória para toda a criação do site**.

Cores principais da referência:

-   Preto: `#000000`
-   Branco: `#FFFFFF`
-   Turquesa/verde-água: aproximadamente `#00C8AD`

Essas cores devem formar a base visual do projeto.

Podem ser utilizadas variações de tonalidade, transparências, gradientes
e tratamentos derivados da paleta quando isso melhorar o resultado
visual.

Não devem ser introduzidas cores de destaque que descaracterizem a
identidade visual definida pela referência.

### Logo

A marca **BASKET WORKING** presente no arquivo de referência deve ser
utilizada no lugar da logo placeholder da FIBA 3x3.

Essa é a marca que deve orientar a identidade visual do site.

A logo pode receber adaptações de aplicação quando necessário,
incluindo:

-   Redimensionamento
-   Recorte adequado
-   Ajustes de contraste
-   Versão monocromática
-   Brilho ou sombra
-   Pequenos ajustes de composição para integração ao layout

Essas adaptações não devem descaracterizar a marca.

O arquivo de referência visual deve ser mantido como fonte principal
para a aplicação da logo e da identidade.

------------------------------------------------------------------------

## 5. Aplicação da identidade na introdução

A introdução deve utilizar a identidade **BASKET WORKING** em vez da
logo FIBA 3x3.

A composição visual deve combinar:

-   Fundo predominantemente preto
-   Elementos brancos
-   Turquesa como cor de destaque
-   Tipografia forte
-   Animações suaves
-   Estética esportiva
-   Sensação cinematográfica
-   Alto contraste
-   Aparência profissional e moderna

A identidade visual deve permanecer consistente durante toda a animação.

------------------------------------------------------------------------

## 6. Diretrizes técnicas da introdução

-   HTML semântico.
-   CSS organizado.
-   JavaScript apenas quando necessário.
-   Preferir CSS para as animações.
-   JavaScript deve ser usado principalmente para controle da interação
    e da transição.
-   Responsividade para desktop e dispositivos móveis.
-   Boa performance.
-   Acessibilidade.
-   Código limpo e modular.
-   A estrutura deve facilitar a substituição futura de assets sem
    necessidade de reconstruir toda a introdução.

------------------------------------------------------------------------

## 7. Regra de escopo

Neste momento, implementar e alterar **somente a introdução**.

Não criar nem desenvolver:

-   Hero principal
-   Categorias
-   Premiação
-   Cronograma
-   Localização
-   Galeria
-   Formulário de inscrição
-   FAQ
-   Rodapé
-   Outras seções da landing page

Essas partes ficam fora do escopo até que a introdução seja finalizada e
aprovada.

# 8. Estrutura visual da landing page após a introdução

## Conceito geral

Após a introdução, a landing page deve seguir uma experiência visual semelhante ao site de referência apresentado pelo usuário.

A intenção é utilizar um **background visual adaptável durante a rolagem da página**, criando uma sensação contínua de movimento e profundidade.

O fundo não deve simplesmente permanecer como uma imagem estática enquanto o conteúdo passa por cima.

Conforme o usuário rolar para baixo, o background deve se adaptar de forma visualmente elegante, podendo utilizar técnicas como:

- Parallax;
- Movimento/transformação do background;
- Alteração suave de escala;
- Posicionamento dinâmico;
- Mudanças sutis de enquadramento;
- Sobreposições e transições entre seções;

A técnica escolhida deve priorizar fluidez, profissionalismo e boa performance, especialmente em dispositivos móveis.

O efeito deve complementar o conteúdo e não prejudicar sua leitura.

---

## 9. Início da landing page

Logo no início da página, após a introdução, a **logo BASKET WORKING deve aparecer em tamanho grande e com bastante presença visual**.

A logo deve continuar utilizando a identidade visual definida no briefing e o arquivo de referência fornecido pelo usuário.

Junto da logo deve existir uma **mensagem de impacto que represente a identidade e a energia do evento**.

Por enquanto, não é necessário definir ou inventar a mensagem definitiva.

O layout deve apenas reservar espaço suficiente para:

- Logo grande;
- Mensagem principal;
- Possível subtítulo complementar;
- Elementos visuais de apoio.

A composição deve ser visualmente forte, limpa e profissional.

---

# 10. Seções iniciais da landing page

Após a área inicial com a logo e a mensagem principal, criar apenas a estrutura visual das seguintes seções:

1. Local do evento
2. Premiações do evento
3. Informações do evento
4. Parceiros do evento

### Regra importante

**NÃO INVENTAR NENHUMA INFORMAÇÃO PARA ESSAS SEÇÕES.**

Neste momento, o objetivo é somente criar a estrutura visual e reservar espaço para que as informações sejam inseridas posteriormente.

Cada seção deve possuir uma área suficientemente grande para permitir uma boa visualização e, futuramente, receber textos, imagens, cards, números, logos ou outros elementos necessários.

---

## 11. Seção — Local do evento

Criar uma seção dedicada exclusivamente ao local do evento.

Por enquanto, não inserir:

- Nome do local;
- Endereço;
- Horário;
- Informações de acesso;
- Mapa;
- Fotos específicas.

Apenas criar uma composição visual profissional com espaço reservado para essas informações futuramente.

A seção deve permitir posteriormente a inclusão de elementos como:

- Título;
- Descrição;
- Imagem do local;
- Mapa;
- Informações de acesso.

---

## 12. Seção — Premiações

Criar uma seção visual dedicada às premiações.

**Não inventar valores, categorias, prêmios ou posições.**

Apenas reservar uma área ampla e visualmente atraente para que posteriormente sejam adicionadas as informações reais.

A estrutura deve permitir futuramente elementos como:

- Título da seção;
- Cards de premiação;
- Valores;
- Troféus;
- Destaques;
- Informações complementares.

---

## 13. Seção — Informações do evento

Criar uma seção ampla para apresentar posteriormente as principais informações do evento.

Não inventar datas, horários, categorias, regras, valores ou qualquer outro dado.

Neste momento, apenas criar a estrutura visual e os espaços necessários para receber essas informações posteriormente.

A estrutura deve ser flexível para acomodar futuramente:

- Textos;
- Cards;
- Ícones;
- Números;
- Datas;
- Horários;
- Categorias;
- Outras informações relevantes.

---

## 14. Seção — Parceiros

Criar uma área visual dedicada aos parceiros do evento.

Não inventar nomes de empresas ou parceiros.

Apenas reservar uma área ampla para inclusão futura das logos e informações dos parceiros.

A seção deve possuir uma apresentação profissional e permitir futuramente:

- Logos;
- Nomes;
- Links;
- Categorias de parceria;
- Outros elementos relacionados.

---

# 15. Direção visual das novas seções

Todas as novas seções devem seguir obrigatoriamente a identidade visual BASKET WORKING já definida neste briefing.

Utilizar como base:

- Preto;
- Branco;
- Turquesa/verde-água;
- Variações derivadas dessas cores;
- Alto contraste;
- Tipografia forte;
- Espaçamento generoso;
- Composição moderna;
- Estética esportiva;
- Aparência profissional.

As seções devem possuir **espaços amplos e visualmente bem definidos**, evitando que a página pareça vazia ou improvisada mesmo antes da inserção dos conteúdos definitivos.

Podem ser utilizados elementos temporários de composição, como:

- Blocos;
- Containers;
- Placeholders visuais;
- Cards vazios;
- Áreas reservadas para imagens;
- Áreas reservadas para textos;
- Elementos decorativos.

Esses elementos devem deixar claro que são espaços reservados e não informações reais do evento.

---

# 16. Regra de conteúdo

Nesta etapa, o Codex deve trabalhar principalmente na **estrutura, composição visual, espaçamento, responsividade e experiência de rolagem**.

Não deve criar dados fictícios para preencher as seções.

O conteúdo real será fornecido posteriormente pelo usuário.

O objetivo desta etapa é criar uma base visual profissional sobre a qual os conteúdos reais serão adicionados depois.
