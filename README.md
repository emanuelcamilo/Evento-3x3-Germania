# Abertura — torneio de basquete 3x3

Esta primeira etapa contém somente a abertura em tela cheia e um estado vazio após a transição. Não há outras seções do site.

## Executar

Abra `index.html` no navegador.

## Personalizar a marca

Substitua `assets/images/placeholder-3x3-mark.svg` pela logo própria do torneio e atualize o atributo `src` em `index.html` se o formato/nome mudar.

O SVG atual é uma marca provisória original; não utiliza o logotipo ou a marca registrada da FIBA/3x3.
